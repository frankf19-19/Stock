# r1189 本股不同狀況與退出時機研究

2,438股（台1,915、美523），承接r1188固定20,514筆原買法進場，三種出場共61,542筆情境（含原賣法）。不是獨立訊號，不是可實行資金年化。台股到2026-10-28、美股到10/27，各股日期另列；最新報價與研究日期分開。

## 這次深入到哪裡

每檔、每種原買法、三個時期，按訊號當時四種情況分開：20日漲跌（−10/+10%）、量對前20日均量（1.5倍）、季線20日方向（0）、離月線距離（0/+10%）。四項各自比較，並非同時成立，事件會重複。門檻預先固定，不依個股最好結果挑選；分類比較容許1e-12浮點誤差，避免持平誤判下降。歷史量比不包含當天分母，所有特徵只用訊號日及以前資料。

固定同一開盤買價，保留原停損、停利、最長持有及開盤優先，再加兩種情境：

1. 累計20個有成交日收盤還沒漲（不高於買價），下一有成交日開盤退出。
2. 收盤獲利至少10%後，從下一日起提高防守到原買價×1.003÷0.997，原防守更高則沿用。盤中最高曾到10%不算；原停利、季線等先到仍先走。跳空可能低於防守，並非保證保本。

每邊0.3%費用，期末未出場留估值；開盤／同根停損優先，下一開盤未發生不捏造成交。原賣法逐筆日期、原因、報酬重現。保本價浮點殘差小於1e-12不當獲利或虧損、避免假的無限獲利因子。

## 實際結果與採用決策

- 台積電低波動突破2024後7筆，原法每筆16.519%，20日沒漲先走7.969%（少8.551個百分點）、獲利後提高防守14.187%（少2.333）。包含1筆期末未出場，不是7筆已實現。
- 欣興高波動跌深止跌＋弱市同期只有2筆，原14.975%，20日沒漲先走20.608%（多5.633）、獲利後提高防守24.551%（多9.577）；少數事件不能據此為本股更換規則。
- 全體6類買法三期，獲利後提高防守的每筆平均全部較原法低；20日沒漲先走偶有改善但不跨三期一致。某些獲利因子較高，是取捨，不是平均／勝率／獲利因子／正年度全面改善。未晉級任何新正式規則。
- 網頁主卡保留明確買進／防守／賣出價；新詳情用最新完整K的本股狀況，查本股各情況的歷史。新研究頁列三期、原與新賣法、全部逐筆日期價格與CSV，不借別股。

## 限制
