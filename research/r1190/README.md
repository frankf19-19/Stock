# r1190 逐股落底與確認方式研究

2438檔（台股1915、美股523），2016起三期、14462個不重疊超跌事件、43386個方法情境。原r1186/r1188可信本機快取先驗SHA，逐股價格SHA一致後才運算；規格在結果前保存。研究快照台股截至2026-10-28、美股10/27，最新主卡另用完整收盤。

比較直接買、20根內等站回10日線且3根未創20根收盤低、等突破前20根盤中高。三法共用第60根個股K終點，未確認／缺下一市場開盤留空手0%，同時列僅成交與完整60根平均。研究−20%防守、台股+50%／美股+30%、每邊0.3%，不是正式90／120日策略績效。逐筆列確認、進出日期與還原價。

沒有跨期全面改善的方法，不能用每檔事後最高報酬挑買法。2024後台積電僅2事件：直接買平均13.451%、等10日線−5.122%、突破0成交（空手2次）；欣興3事件：直接11.243%、等10日線−13.232%、突破只成交1次，含空手平均3.847%；鴻海4事件：直接6.287%、等10日線15.855%、突破只成交1次，含空手4.073%。這些是少樣本描述，不是推薦、勝率或下次報酬。

主卡保留買進／防守／賣出價優先，另加本股收盤結構與下次10日線價、20日高價、固定反彈失效線。已站上不說成新收復買點；固定低點不隨跌勢下移。結構描述與研究的極端分位起點不同，盤中報價不能確認落底。再破低指訊號後20根價格追蹤，包含已退出後；不同方法有不同日期／錨點與成交篩選，不是因果風險降低。樣本不足／未滿20根不當成功。

既有落底模組改用保存的明確除權／分割事件，不從大跌猜因子；融資0與零成交不當利多。逐股日期保存，舊檔無日期不能冒稱收盤止跌；原全市場日觀測統計收合保留並標不是本股勝率。舊統計替換前按原始bytes SHA永久備份。
