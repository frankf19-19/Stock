## 價格與時間如何顯示

開啟report.html，可搜尋每股，查全部六種方法各期筆數／均值／驗證PF。只有開發期選中、通過驗證且當前價位結構合格者列候選價表；研究價、確認收盤日、下個市場交易日一日限價、當日未成交取消、停損／停利與最長持有全部寫清楚。這些是固定截止快照的條件試算，不是已發生的確認或今天一定可掛；確認日過後不能直接採用。沒有固定預測漲到目標的日期。

原價位在前一天鎖定；下一日確認，下一市場交易日才可掛一天限價。開盤低於防守取消；限價成交上限內才模擬。開盤跳空優先、同日雙觸價停損優先；盤中才成交不領取可能先發生的當日高點停利。持有時限按20／40／60根可用交易日K線計，停牌或缺K可能延後，不能保證第幾個市場交易日一定成交出場；分期末未平倉估值保留虧損。來回0.6%。價格展示依台股跳動／美分取整，但回測仍是未取整還原價，不能把兩者說成完全相同的真實撮合。
