# r1166：按個股現況評估進出場價（研究與條件參考）

Frank指出原本只等個股自60日高跌40%／35%太遠，要求按每檔狀況評估適合的買賣價。本批新增逐股條件計畫，原極端跌深與台股創高策略完整收合保留；不修改AI Pick選股、持倉、撮合、推播或正式交易訊號。

## 結論與禁止事項

研究2422檔（TW1899／US523），價格自2012起建立指標、2016起分2016–2020／2021–2026兩段。不是每檔都適合新買法。現況粗篩：555檔價位結構不合、1764檔前後期完成樣本不足、90檔表現不穩，只有13檔保留進一步評估資格；後者仍未證明優於原策略，零個新策略自動晉級。這些是未取合法價格跳動及即時失效前的研究分類，不是13檔即時買進清單。

台積電現況屬轉弱待收復，研究這種情境前後期各5筆；後期平均為負，不能包裝成已驗證買點。台股上升回檔情境兩段事件平均皆負；美股上升回檔前期正、後期負。僅靠拉近買價或設定1.5倍報酬風險比，沒有證明更好。

網站先顯示「現在先不買」或待條件評估的動作，再列每股數字、失效價及反彈賣價。未通過本股歷史／資料／價位檢查者，數字只能供重新評估，不能按價直接進場。即使本股初篩通過，仍明標新買法在研究；不能宣稱最佳買點／已驗證勝率／保證成交。

## 走勢與價格（固定規格，非逐檔事後最佳化）

20日平均真實波幅用簡單平均，非Wilder ATR。全部取完整收盤資料；盤中報價只判斷計畫是否失效，不回填指標。

- 上升：收盤與20日均線在60日均線上、60日均線較10日前上升超過0.25個波幅。買價上限取20日均線、收盤下0.25波幅、1.5倍空間限制三者最低；退出在20日低下0.5波幅，反彈價看60日高。
- 轉弱：收盤低於60日均線0.5波幅，或60日均線較10日前下滑超過0.25波幅。等收盤站回上方較近20／60日均線，評估價上限為該線上0.25波幅；退出在20日低下0.5波幅、反彈價看60日高。
- 其餘為盤整：低接上限取20日低上0.25波幅、收盤下0.25波幅與1.5倍空間限制最低；退出在60日低下0.5波幅、反彈價看20日高。

買區下緣為上限下0.25波幅。原始風險至少0.5波幅且毛報酬空間／風險至少1.5才有效。前端依TW跳動或US美分取整，取整後成本賺賠比不高於1、價位倒置／非正數時不採用。這是參考計畫，不是合理估值；沒有用目前EPS、財報或法人資料回填歷史訊號。

## 歷史回放與保守處理

計畫使用確認日前一日已知的價位。轉弱等確認日收盤站回原線；其餘等確認日收盤不低於前一日，且最低價接近原買價（上0.5波幅以內）。確認日低點已破退出價或收盤已超賣價則取消。下一市場交易日只做原上限以下的一日限價：開盤在上限以下且高於退出價按開盤；否則當日低觸上限才按上限估計成交。缺下個市場交易日／零量則取消，沒有停牌後無限等待。

來回0.6%（各0.3%）；同股不重疊，最長40根交易K。開盤跳空優先；同根雙觸價先算退出。盤中才成交時，不把同日可能在成交前出現的高點當成可停利。分期末未平倉按最後可用收盤含估計賣出費用列boundary_mark，保留虧損，不冒充已完成交易。這是事件研究，沒有資金組合年化／最大回撤結論。價格未做歷史整股、升降單位、排隊／漲跌停、衝擊與實際稅費撮合。

本股初篩只用當下情境對應樣本：前後期各至少10筆非boundary完成樣本、各期平均正、PF>=1.1、至少半數有交易年份為正。這不是統計顯著檢定；無樣本／全贏無有限PF不當成高把握。全期間挑最好的情境不部署。現在使用的股票庫有倖存者偏差，歷史早已被其他研究看過，不能稱為未見驗證。
