# r1188 逐股同進場買賣路徑研究

承接 r1186 固定資料，2,438 股（台1,915、美523），20,514 筆原買法事件、102,570 筆同進場出場情境。不同買法可能包含相同進場，不是獨立樣本，更不是資金年化。台股至2026-10-28、美股至10/27，各股實際末日另列；不是當前報價。

## 如何讀

- 主卡原買進／防守／賣出價格仍保留；新增「本股買賣特性」與同分頁研究入口，不把歷史達標日數當預測。
- 每股、每買法、三個時期各自統計：進場後可確認回落、曾達5/10/20%與達到者日數、停損後20日回成本、停利後20日價格變動、持有中波動類別改變。無事件列無資料，不借別股。
- 固定同一進場日／開盤價，比較原賣法、季線兩日、固定出場、最高收盤回落15%、較緊防守。原方法逐筆出場日、原因及淨報酬均精確重現；五種方法包含原方法。不是各自重新挑最漂亮的進場。
- 每邊0.3%成本；期末未出場虧損保留。畫面同列全事件及兩方均完成對照，不只挑贏家。
- 盤中／開盤出場日排除整根日K高低，只用已知賣價；回落與觸價是可確認下限。到期收盤／期末估值才允許該日全根。日數按本股有紀錄日期計算，停牌或缺K可能等待更久。
- 停損後20根有成交日K收盤回到原含買賣成本門檻；不足20根或跨分期列待觀察。停利後20日變動不是再買入報酬。事後反彈不證明停損錯誤。
- 所有時期均曾研究，不是全新未見樣本；沿用當前股庫、還原K、缺完整下市與鎖單等限制。少數個股交易不能證實最佳賣法，沒有自動採用個股最高數字。

## 持股修正

只填成本無法知道原本買法。舊畫面曾由今天波動分類決定持股出場，會在持有中變換規則。本版列三種有條件的原方案，明確要求沿用買入時採用者；不改私人偏好、成本、模型、通知或正式進出條件。
