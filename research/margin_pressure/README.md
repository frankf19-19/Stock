# r1193 逐股融資餘額與成本情境

這是公開資料的算式與現況描述，沒有新增買賣規則、斷頭機率、風險分數或已驗證投資訊號。

## 哪些可以知道

- 本股實際公布的融資餘額（張）及標示日期。
- 近5／20／60個市場交易日兩端增減張數與百分比；缺中間日明列，不把6筆觀測偷當5個市場交易日。
- 完整近60個交易日內的餘額高峰、日期、至今減少張數與百分比；缺日或歸零／異常跳動不說已洗掉100%。
- 與同起訖日股價變化一起描述：「融資減少但價格仍跌」、「融資增加、價格偏弱」等，不辨識主力／散戶身分，不宣稱餘額下降就是斷頭、賣壓結束或底部。

## 哪些不知道

公開個股淨餘額沒有存續融資戶買價、實際借款、融券部位、利息、抵繳品與其他股票，也沒有補繳及券商通知資訊。因此無法推算真實整戶維持率，不能回答某股票「一定還差幾%就爆」。融資減少可能來自賣出還款、現金償還、其他調整，不一定是強制處分。缺資金流入／償還明細時，不用淨增加日加權價冒充存續融資成本。

## 明示的單筆情境

分別假設買在本股近20日平均收盤、20日最高收盤、60日最高收盤，借款為買價60%，未還款、無抵繳品；以目前有效價格計算：

- 情境維持率＝目前價格÷（假設買價×60%）×100%。
- 130%情境價＝假設買價×60%×130%＝假設買價×0.78。
- 距離＝（情境價÷目前價格−1）×100%。負值表示還要跌多少；正值表示已在該情境線下、需要回升多少回線。這不是實際追繳或斷頭指令，券商採整戶管理且有通知／補繳程序。

未計股利、利息、實際融資成數、還款、融券及抵繳；歷史價格用現有未還原收盤作成本假設，不當成實際融資戶成本。顯示2位小數供試算，未取成可下單跳動單位。美股／ETF不套此台股個股情境。

## 來源與保存

build_margin_pressure.py只讀既有公開archive/margin/tw前一年及當年（欄mb）、c/tw（cd/mf）、margin.json.hist及k/tw（d/o）；依市場K日期聯集，剔除週末／holidays與未完成／未來日。較新來源優先同日；每個來源bytes SHA放在輸出的sources，不呼叫付費API、不讀帳戶或金鑰。官方資料透過現有TWSE／TPEx及FinMind保存鏈取得；FinMind只用盤後資料。

margin_pressure.json.gz和CSV是最新輕量衍生檔，完整每次結果按內容SHA另存archive/stock_research/margin_pressure/日期/，不刪舊結果。fetch_margin在覆蓋舊檔前保存舊／新公開快照於archive/hist/margin/資料日/SHA.json.gz，active.json明確指向目前各日版本；相同內容不重複，修訂永久保留。舊12筆前端視圖繼續存在，永久資料不再因視圖截斷而消失。

主卡按需下載一次、完成保留開合並刷新；缺資料或錯股票／未來日期不借其他股票數字。最新價格變化只重算情境，不改歷史融資餘額、持股成本、正式買賣策略或通知偏好。舊大盤「融資維持率」改標指數成本情境，保留原計算來源，停止把此指數近似當整戶斷頭警訊。
