# r1186 逐股買賣執行與成本壓力測試

本批以 r1185 為基準，固定比較七種方式，不按個股最漂亮的結果挑買法，也未把比較結果自動接成新買單。正式網頁保留買進／防守／賣出三欄；新研究頁從每檔主卡直接進入。

## 資料與結果

- 2,438檔：台股1,915、美股523；長期庫2012起加近期K線，台股到2026-10-28、美股可用資料到2026-10-27，各股末日另列。研究截止上限10/28，不能把缺少的美股10/28編造補齊。
- 139,885筆「策略變體×分期」模擬逐筆紀錄，非139,885個互相獨立訊號。2016–2020開發、2021–2023驗證、2024後稽核；這些年份已被研究，不能稱為真正未見樣本。
- 比較：既有買法對照、只看52週首次新高、下一交易日按訊號收盤價限價一天、跳空超3%取消、季線兩日出場、突破固定−15/+30/90、最高已知收盤回落15%防守。部分不適用於該買法的變體與基準相同，全部原結果保留。
- 每筆成本0.6%，另算1%壓力；不使用當前財報或現在股數回填歷史。開盤優先，盤中同根觸及採停損優先；限價盤中買入，不假設同日最高點一定在買進後。期末未出場按最後收盤扣估計出場費保留，不能丟掉未實現虧損。
- 資金曲線為每股／每買法各一份起始現金、同股單一部位、股與股不重分配，未上市或未觸發期間保留現金。全體是當前股庫等起始資金加總；不是可實行的五檔帳戶。日收盤回落不是盤中最大虧損。

## 重要發現與實際修正

1. 限價或跳空取消沒有全面改善資金結果。例：高波動跌25%止跌在2021–2023，限價成交那批平均較好，但成交減少，等起始資金結果較弱；不能只拿已成交平均就宣稱買得更好。完整三期及成本結果見report.html。
2. 高波動突破2021–2023每筆約+0.78%，2024後約+7.72%，期間差異大；不能把十年平均當逐次預期。低波動固定出場、中高波動季線持有、跌深長等待都有自己的取捨；本批不自動晉級任何新變體。
3. 網頁中高波動主卡仍寫+30%先賣一半，但r1178出場研究說固定／分批較差。本批去除該額外賣法，依既有季線兩日規則；低波動完整說明同步−15/+30/90，個人成本仍與模型分開。
4. 市場寬度缺值、空字串、布林、陣列、非法數字不能當0%放行；資料必須對上本股訊號日，有a60h則按該日讀，較舊資料會節流重讀。缺資料不發新買進結論。
5. 原訊號的開盤已過，不能改標未來開盤直接買；缺完整收盤／日曆只保留價格供核對，暫不掛新單。原r1169觀察通知、偏好、AI模型、會計、原財報及歷史資料均未改。

## 保存與重現

- `execution-audit.json.gz`：完整研究，`TW-ledger.json.gz`／`US-ledger.json.gz`：全部逐筆，`profiles.json.gz`：瀏覽器輕量衍生，均永久保留。
- `engine-used.py`／`loader-used.py`是實際運算原碼快照，SHA與完整JSON及sources.json一致；根目錄stock_execution_audit.py、stock_execution_data.py是相同引擎的可重跑入口。先取sources.json所列source_commit的資料，再使用本版引擎，安裝既有numpy/pandas，在新目錄執行：`python stock_execution_audit.py --output outputs/new-research --asof 2026-10-28`。完成目錄不可覆寫；要重跑換目錄。
- 近期K同日優先、還原因子按事件日期去重，來源每檔有SHA。Windows來源路徑分隔符驗證時可改成`/`；以每檔內容SHA為準。
- 初次純歷史庫結果已封存Frank本機`outputs/Stock-r1186-歷史庫單獨研究原始備份.zip`及完整JSON；後續發現近期K未接合，保留舊結果後才重跑。不得拿該初版日期或數字混成這份最終版。
- 可重現不等於實盤保證：仍有當前股庫／修訂資料偏差，無完整下市母體、逐筆排隊、漲跌停鎖單、真實稅率及歷史跳動單位重播。市場交易日由現有全市場日K推導，可能漏掉全市場缺資料日。個股樣本少時不借另一檔的勝率，也不按全期最好變體換規則。
